### 3.3 玻璃质感基线（`GLASS_SVG_TEXTURE.md` 的精髓）

**用户明确不接受的**（我们的验收标准同样适用）：
- 普通毛玻璃、没有扭曲质感；
- 中间糊成一团；
- 大面积白色渐变扫过去的廉价感；
- 因套用 SVG 导致性能明显下降。

**做法**：`feTurbulence` 生成噪声 → `feDisplacementMap` 做**水波扭曲** → R/G/B 三通道**分离色差** → `screen` 混合 → `feGaussianBlur stdDeviation=0.5` 收边。
参数：displacement scale Red `180` / Green `170` / Blue `160`，共同中心 `dx=-90`，色差下限 `30`。

**渐进增强**：SVG 滤镜可用时给 `html` 加 `control-glass-svg-ok` 类切换到折射玻璃；不可用时退回 `blur()`。
—— 本项目照此模式实现 `html.lims-glass-svg-ok`。

### 3.4 圆角比例尺

`6 / 8 / 10 / 12 / 14 / 18 / 20 / 22 / 24 / 28 / 34 / 50 / 999px / 50%`
—— 特点：**面板级敢用大圆角**（22–50px），按钮/胶囊用 `999px`，小标签用 `6–8px`。

### 3.5 动效

| 曲线 | 用途 |
|---|---|
| `cubic-bezier(.16,1,.3,1)` | 主缓出（进场、位移） |
| `cubic-bezier(.2,.8,.2,1)` | 窗口/快速位移 |
| `cubic-bezier(.2,.7,.2,1)` | 搜索区定位 |
| `cubic-bezier(.22,1,.36,1)` | 长进场（4–5.2s 启动动画） |

时长：短态 `.17–.28s`；进场 `.45–.76s`；氛围动画 `1.5–18s` 无限循环。
**无障碍**：`@media (prefers-reduced-motion: reduce)` 全部 `transition/animation: none`。

## 4. LIMS 的适配决策（为什么不能照搬）

| 维度 | Mineradio | LIMS 应有做法 | 理由 |
|---|---|---|---|
| 主题 | 纯暗色沉浸 | **暗色为默认**，但保留浅色令牌槽位 | 实验室有强光环境，未来可能需要浅色 |
| 装饰密度 | 极高（粒子/镜头/3D 架） | **克制的静态极光背景 + 玻璃卡片** | 检验员每天录入数百条数据，动态粒子会分散注意力 |
| 字体 | 10–13px 小字为主 | **13–14px 正文，表格 13px** | 长时间录入可读性优先 |
| 强调色 | 青 `#00F5D4` 直接做按钮 | 青**只做光晕/激活条**；按钮用 **青→蓝渐变**（`#0EA5A0`→`#2442FF`） | 浅青底 + 白字对比度不足，按钮会看不清 |
| 圆角 | 面板 22–50px | 卡片 **14–18px**、按钮/胶囊 `999px`、标签 `8px` | 50px 圆角会切掉表格四角，数据区域不适用 |
| 动效 | 4–5s 长进场 | 进场 **.28–.45s** | 办公系统要「快」，不要仪式感 |
| 语义色 | 平台源色 | 合格/不合格/待判定 + **涨红跌绿** | 报告结论与金融惯例 |

**一句话原则**：
> **沉浸式视觉只用于「外壳与关键卡片」，数据密集区（表格/表单）用高对比玻璃面板保证可读性。**
> 华丽要出现在**第一眼**（登录页、侧栏、工作台），而不是出现在**填写数据的地方**。

## 6. 可复用结论（写进技能库）

1. **「华丽」= 配色关系 + 质感 + 动效曲线三者同时成立**，不是加装饰。缺任一项都会显得廉价。
2. **暗色系统最忌「灰糊」**：底色要够深（≤`#0A0B0D`），表面靠**1px 白色内发光**（`inset 0 1px 0 rgba(255,255,255,.16)`）而非提高底色明度来区分层级。
3. **玻璃要有扭曲才算玻璃**：纯 `blur()` 是廉价感的根源。用 SVG `feTurbulence + feDisplacementMap` 做折射，并用**渐进增强**兜底性能。
4. **强调色 ≠ 按钮底色**：浅色强调色（青/薄荷）做光晕与激活条，按钮用**深一点的渐变**保证白字对比度。
5. **参考第三方 UI 必查许可**：GPL/AGPL 项目只能借鉴「思想与参数关系」，代码必须独立重写。
6. **办公系统的动效预算 ≤0.45s**；氛围动画必须 `prefers-reduced-motion` 可关。
